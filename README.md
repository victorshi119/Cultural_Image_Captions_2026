## System Overview

Our system prompts Gemma 4 31B with a fixed base context (grammar book + interlinear glosses) augmented by per-image retrieval from multiple resource pools. We submitted 9 configurations covering two retrieval strategies: **text BM25** and **visual few-shot**.

All runs share:
- Model: `gemma-4-31B-it` via REALLMs
- Prompt: version `v3` (Spanish-language guidelines)
- Grammar book: 157 lines from `resources/guarani_ref.md`
- Interlinear glosses: 144 lines from `resources/guarani_grammar_primer_claude.md`

## Final Submission Configurations

Each submission file in `submissions/final/` is a JSONL with one record per test image. Fields: `id`, `filename`, `split`, `culture`, `language`, `iso_lang`, `predicted_caption`. The only field that varies across files is `predicted_caption`.

Files were generated by `finale.slurm` (SLURM array job, IDs 0–8) and merged with test metadata via `merge_predictions.py`.

### Text BM25 Runs — `guarani-0` through `guarani-5`

BM25 retrieves per-image context dynamically from four resource pools. The sweep varies retrieval depth across pools:

| File | Source TSV | DAMPY_K | FLORES_K | DEV_K | CULTURE_K |
|---|---|---|---|---|---|
| `guarani-0.jsonl` | `finale_text_0.tsv` | 5 | 100 | 5 | 5 |
| `guarani-1.jsonl` | `finale_text_1.tsv` | 10 | 100 | 10 | 5 |
| `guarani-2.jsonl` | `finale_text_2.tsv` | 15 | 100 | 10 | 5 |
| `guarani-3.jsonl` | `finale_text_3.tsv` | 20 | 100 | 10 | 6 |
| `guarani-4.jsonl` | `finale_text_4.tsv` | 15 | 120 | 10 | 8 |
| `guarani-5.jsonl` | `finale_text_5.tsv` | 15 | 150 | 10 | 10 |

**DAMPY_K** — top-K Guaraní + Spanish DAMPY caption pairs retrieved by BM25 from image text  
**FLORES_K** — top-K EN→GN FLORES parallel sentence pairs retrieved by BM25  
**DEV_K** — top-K dev set image–caption pairs retrieved by text BM25  
**CULTURE_K** — top-K chunks from the Guaraní cultural knowledge file retrieved by BM25

### Visual Few-Shot Runs — `guarani-6` through `guarani-8`

These runs drop text-based DAMPY retrieval and instead inject actual DAMPY images as visual few-shot turns in the prompt. Dev exemplars are retrieved by **image similarity** (visual BM25) rather than text. Culture knowledge is injected as a fixed 5-chunk context.

| File | Source TSV | Visual DAMPY shots | FLORES_K | DEV_K |
|---|---|---|---|---|
| `guarani-6.jsonl` | `finale_visual_15shot.tsv` | 15 | 100 | 10 |
| `guarani-7.jsonl` | `finale_visual_25shot.tsv` | 25 | 100 | 15 |
| `guarani-8.jsonl` | `finale_visual_50shot.tsv` | 50 | 100 | 20 |

### Why Both Strategies

chrF++ measures character n-gram overlap and has two blind spots for this task: it is insensitive to semantic paraphrase (a correct but differently-worded caption scores low) and cannot detect cultural item misidentification (calling *mate* equipment *tereré* is penalized the same as any other lexical mismatch).

- **Text BM25 runs** optimize for retrieval breadth and vocabulary overlap with gold labels, which benefits chrF++.
- **Visual few-shot runs** prioritize semantic and visual grounding: by retrieving the most visually similar dev examples and injecting real image–caption pairs, the model is more likely to correctly identify culturally specific items even when the surface form diverges from the reference.

Submitting both strategies gave coverage across both dimensions. Qualitative analysis showed the visual runs were the only ones to correctly distinguish *mate* from *tereré* equipment (grn_052), where the discriminating visual cue — a metal kettle (*pava*) vs. a cold thermos (*térmo*) — requires seeing the image, not just matching text.

## Dev-Set Results

### Text BM25 sweep (Gemma 4 31B, prompt v3)

Evaluated on `data/dev/guarani/guarani.jsonl`. Smaller retrieval depth scored higher on chrF++ because larger context encouraged repetitive boilerplate closings.

| Config | DAMPY_K | FLORES_K | DEV_K | CULTURE_K | chrF++ |
|---|---|---|---|---|---|
| text_0 | 5 | 100 | 5 | 5 | **22.40** |
| text_1 | 10 | 100 | 10 | 5 | 22.02 |
| text_2 | 15 | 100 | 10 | 5 | 21.59 |
| text_3 | 20 | 100 | 10 | 6 | 21.90 |
| text_4 | 15 | 120 | 10 | 8 | 21.44 |
| text_5 | 15 | 150 | 10 | 10 | 20.43 |

### Static visual few-shot sweep

Visual few-shot runs consistently outperformed text-only runs across all configurations.

| Config | Visual shots | FLORES | DEV visual | chrF++ |
|---|---|---|---|---|
| visual_5shot | 5 | 30 | — | 23.49 |
| visual_10shot | 10 | 30 | — | 24.17 |
| visual_15shot | 15 | 50 | — | **24.43** |

### Ablation results (dev set, prompt v3, 3 runs averaged)

Add-one-forward ablation — each resource added to the base prompt in isolation. Scores are mean chrF++ averaged over 3 independent runs (jobs 6966213, 6966221, 6966222).

Resources:
- `ck` — culture knowledge (`Claude_2step_guarani_cultural_knowledge.txt`)
- `il` — interlinear examples (`guarani_grammar_primer_claude.md`, full)
- `gp` — grammar parallel (`guarani_exemplar_bank_claude.md`, full)
- `ap` — apertium (`apertium-grn-caption-cheatsheet.md`)
- `pe` — FLORES parallel examples (`flores_dev_examples_en-gn.json`, full)
- `dampy` — DAMPY cultural caption exemplars (`dampy_gemma_claude_caption.txt`, full)

| Condition | r0 | r1 | r2 | Avg |
|---|---|---|---|---|
| none | 20.15 | 20.13 | 20.55 | **20.28** |
| +pe | 23.37 | 22.65 | 23.18 | **23.07** |
| +ck | 21.02 | 20.86 | 20.78 | **20.89** |
| +il | 21.76 | 20.94 | 20.84 | **21.18** |
| +dampy | 21.33 | 20.70 | 20.69 | **20.91** |
| +gp | 19.28 | 19.37 | 19.54 | **19.40** |
| +ap | 17.51 | 17.27 | 18.02 | **17.60** |
| all | 22.14 | 22.20 | 21.96 | **22.10** |

FLORES parallel examples (`pe`) is the strongest single augmentation. Grammar parallel (`gp`) and Apertium (`ap`) hurt performance. FLORES parallel examples (`pe`) is the strongest single augmentation for both prompts.

## Usage

`main.py` takes a folder of images and generates Guaraní captions via the REaLLMs VLM API.

```bash
python main.py <image_dir> [options]
```

### Minimal run

```bash
python main.py data/dev/guarani/images --output outputs/captions.tsv
```

### Full run (best visual configuration)

```bash
python main.py data/test/guarani/images \
    --model gemma-4-31B-it \
    --prompt_version v3 \
    --output outputs/finale_visual_15shot.tsv \
    \
    --culture_bm25 resources/Claude_2step_guarani_cultural_knowledge.txt \
    --culture_bm25_top_k 5 \
    \
    --grammar_book resources/guarani_ref.md \
    --num_grammar_book 157 \
    \
    --interlinear resources/guarani_grammar_primer_claude.md \
    --num_interlinear 144 \
    \
    --flores_bm25 resources/flores_dev_examples_en-gn.json \
    --flores_bm25_top_k 100 \
    \
    --dev_jsonl data/dev/guarani/guarani_trilingual.jsonl \
    --dev_images_dir data/dev/guarani/images \
    --dev_bm25_text_top_k 10 \
    \
    --dampy_images new_data/dampy_output/images \
    --dampy_captions resources/dampy_gemma_claude_caption.txt \
    --num_dampy_shots 15
```

### Arguments

| Argument | Default | Description |
|---|---|---|
| `image_dir` | required | Folder of input images (jpg/png/webp/bmp) |
| `--model` | `gemma-4-31B-it` | Model name on REaLLMs |
| `--prompt_version` | `v2` | Base system prompt: `v2` (English rules), `v3`/`v4` (Spanish guidelines) |
| `--culture_knowledge` | — | Guaraní cultural knowledge file (static, full) |
| `--culture_bm25` / `--culture_bm25_top_k` | — / 5 | Cultural knowledge file with BM25 retrieval per image |
| `--interlinear` / `--num_interlinear` | — / 8 | Interlinear glossed examples injected into prompt |
| `--grammar_book` / `--num_grammar_book` | — / — | Grammar book parallel sentences |
| `--apertium` / `--apertium_chars` | — / 15000 | Apertium morphology summary (truncated to N chars) |
| `--flores_bm25` / `--flores_bm25_top_k` | — / 10 | FLORES EN→GN parallel examples with BM25 retrieval |
| `--parallel_examples` / `--num_parallel` | — / 10 | FLORES EN→GN parallel examples (static) |
| `--code_rules` / `--retrieval_top_k` | — / 10 | Code-format grammar rules with BM25 retrieval per image |
| `--dampy_captions` / `--num_dampy_shots` | — / — | DAMPY captions for visual few-shot (static) |
| `--dampy_images` | — | DAMPY image directory for visual few-shot injection |
| `--dampy_bm25_top_k` | — | DAMPY text BM25 retrieval depth |
| `--dev_jsonl` / `--dev_images_dir` | — | Dev set for few-shot retrieval |
| `--dev_bm25_text_top_k` | — | Dev set text BM25 retrieval depth |
| `--output` | `generated_captions.tsv` | Output file (`image_name\tcaption` per line) |

### Merge TSV predictions into submission JSONL

```bash
python merge_predictions.py \
    --jsonl data/test/guarani/guarani.jsonl \
    --tsv outputs/finale_visual_15shot.tsv \
    --output submissions/final/guarani-6.jsonl
```

### Evaluation

```bash
python eval_chrf.py --dataframe data/dev/guarani/guarani.jsonl --generated outputs/captions.tsv
```

Reports mean chrF++ score per image.
